# فرقعة البالونات الملونة

لعبة عربية تعليمية صغيرة مبنية بـ HTML وCSS وJavaScript، هدفها الضغط على البالونات التي تطابق اللون المطلوب خلال 60 ثانية.

## المزايا

- عداد وقت مرئي مع شريط تقدم وتحذير عند اقتراب النهاية.
- ألوان زاهية وتدرجات وإضاءة ولمعان للبالونات.
- مؤثرات صوتية مولدة عبر Web Audio API دون ملفات صوت خارجية.
- شاشة بدء ونهاية وإعادة تشغيل.
- دعم الماوس واللمس عبر Pointer Events.
- تصميم متجاوب مع شاشات الهاتف والحاسوب.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً بسيطاً:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

> قد يحتاج الصوت إلى أول نقرة من المستخدم بسبب سياسات المتصفحات الخاصة بتشغيل الصوت تلقائياً.
